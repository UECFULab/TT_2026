To perform muscle synergy analysis using NNMF on a filtered EMG dataset, run “makeNMF_Human_TenTrans.m”.
To plot EMG data, run “plot_emg.m”.
To plot joint angle trajectories and %TAM for each measurement day, run “plot_SegmentAngle.m”.
To plot the spatiotemporal patterns of muscle synergies, run “plot_synergy.m”.
To plot the results of the correlation analysis between synergies across measurement days, run “plot_synergy_correlation.m”.
To plot the MMD values of synergies across measurement days, run “plot_synergy_MMD.m”.
To plot the VAF values for each measurement day, run “plot_vaf.m”.
