“makeNMF_Human_TenTrans.m”: Perform muscle synergy analysis using NNMF on a filtered EMG dataset.

“plot_emg.m”: Plot EMG data.

“plot_SegmentAngle.m”: Plot joint angle trajectories and %TAM for each measurement day.
